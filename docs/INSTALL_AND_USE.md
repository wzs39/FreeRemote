# FreeRemote 安装与使用完整教程

> 从零开始：装电脑端 → 手机连上 → 跨网络远程 → 开机自启 + 远程唤醒。本文从头讲到尾，
> 深挖细节看旁边的专用文档（文末有文档清单）。

---

## 一、这是什么 / 怎么运行的

FreeRemote 让你用**手机浏览器**远程操作电脑：实时看屏幕、点鼠标、打字、传文件。

它分两部分：

| 部分 | 是谁 | 作用 | 跑在哪 |
|---|---|---|---|
| `server.py` | 被控制的电脑 | 抓屏幕、接收指令、执行键鼠 | **你的电脑**（必须装在被控机上） |
| `relay.py` | 中继服务器 | 手机与电脑之间的桥（识别码配对） | 可选；跨网络才需要 |

两种运行模式：

- **局域网模式**：手机和电脑连同一个 WiFi，直接连电脑，不需要中继
- **识别码模式（中继）**：手机和电脑在不同网络，通过中继互通（像 RustDesk）

## 二、电脑端安装

### 前置要求
- Python 3.9+（官网 python.org 下载，安装时勾选 Add to PATH）
- Windows / macOS / Linux 均可

### Windows
双击 `run.bat`。首次运行会自动：创建 `.venv` 虚拟环境 → 联网安装依赖（aiohttp/mss/Pillow/pyautogui/pyperclip/qrcode）→ 启动服务。

> 首次安装依赖需联网，之后离线可正常用。

### macOS / Linux
```bash
./run.sh
# 若提示权限不足：chmod +x run.sh 后再执行
```

安装完成后电脑终端会打印**实时可用的手机访问网址**和**二维码**：

- 局域网模式：打印 `http://<最可能的IP>:8080/?token=xxxx` 及全部候选网卡网址，并打印一个二维码
- **用手机相机直接扫终端二维码** → 自动打开并带 token 登录，连网址都不用敲
- 识别码模式：额外打印识别码、口令和登录二维码

> 提示：多网卡（WiFi+有线+VPN）机器上可能列多个网址，手机连哪个网就用哪个；首选标着 `← 最可能` 的那条。

## 三、方式一：局域网使用（最快上手）

1. 电脑跑 `run.bat`（或 `run.sh`）
2. 手机连**同一个 WiFi**
3. 手机浏览器打开电脑终端的链接（例如 `http://192.168.1.103:8080/`）
4. 首次会弹出登录框 → 输入终端里的**口令** → 「连接」
5. 看到电脑桌面即可操作

> 打不开手机端？Windows 防火墙拦截了 —— 管理员运行一次：
> `netsh advfirewall firewall add rule name="FreeRemote" dir=in action=allow protocol=TCP localport=8080`

**常用命令：**
| 场景 | 命令 |
|---|---|
| 启动 | `run.bat`（或 `./run.sh`） |
| 停止所有 FreeRemote 进程 | `stop.bat`（`./stop.sh`） |
| 一键体检 + 修复建议 | `doctor.bat`（`doctor.sh`） |
| 指定共享文件夹 / 画质 | `run.bat --share-dir "D:\共享" --preset high` |

## 四、方式二：跨网络远程（中继）

手机和电脑**不在同一网**时，需要一台「中继」。三种来源任选：

### 4.1 直接买/借一台公网服务器跑 Docker（推荐，可控）
把项目拷到服务器：
```bash
docker build -t freeremote-relay:latest .
cp .env.example .env            # 填 DOMAIN / RELAY_DEVICES / RELAY_STRICT
docker compose -f docker-compose.https.yml up -d --build    # Caddy 自动 HTTPS
```
详细：`docs/DEPLOY_DOCKER.md`

### 4.2 免费托管平台（Render / Fly.io，零成本）
按 `docs/DEPLOY_RELAY.md` 一步步来，自动拿到 `https://域名`（HTTPS/wss 自带）。

### 连接（中继就绪后）
- **电脑端（双击版，推荐）**：第一次双击 `run.bat`，按提示输入 `Y` → 中继地址 / 识别码 / 口令，
  自动存到 `relay-config.txt`；**以后每次双击 `run.bat` 自动连中继**，无需再输。
- **电脑端（命令行版）**：
  ```bat
  run.bat --relay wss://你的中继域名 --id TEST01 --password 你设的强口令
  ```
  带 `--relay` 启动时参数也会自动存进 `relay-config.txt`（供开机自启用）。启动会打印二维码 → 或用手机输识别码+口令登录。
- **手机端**：打开 `https://你的中继域名/` → 输入识别码`TEST01` + 口令 → 登录。

> 中继端务必用 `--devices "识别码:强口令" --strict`（只允许登记的识别码连接）。

## 五、开机自启 + 远程唤醒（关机也能开机）

把这套配好，你的电脑就变成「可随时远程开/关」的常任设备：

1. **开机自启**：电脑以中继模式运行过一次后，跑
   ```bat
   install-autostart.bat
   ```
   （把 `python server.py --relay ...` 注册成 Windows 登录自启任务）
2. **电脑自动登录**：设置 Windows 自动登录（登录到桌面，任务才会触发）
3. **远程唤醒**：在 BIOS 和网卡驱动里启用 **Wake-on-LAN**，记下电脑网卡 MAC
4. **中继配置唤醒**：中继加 `--wol "TEST01:你的MAC"`（Docker 用 `RELAY_WOL=TEST01:你的MAC`）
5. 之后手机打开，设备离线时点「⚡ 唤醒」→ 电脑开机 → 自动连回中继 → 恢复在线

> 前提：中继与电脑在同一局域网。

## 六、手机端使用全解

### 登录
- 局域网：输口令
- 识别码模式：识别码 + 口令，或**用相机扫电脑终端二维码**（自动登录，口令不进码）

### 监看与控制
| 手势 | 效果 |
|---|---|
| 单击 | 左键 |
| 长按 | 右键 |
| 拖动 | 移动鼠标 |
| 双指 | 滚轮 |
| 工具栏大按钮 | 左/右/中键、滚上/下、全屏 |

横屏布局：画面在左、控制按钮在右，右手拇指正好落在按钮区（竖屏会提示转横屏）。

### 打字
点「⌨ 键盘」→ 输入后回车：
- **英文/符号**：电脑端直接逐键敲出（不依赖剪贴板，稳）
- **中文**：以粘贴方式输入（会占用电脑剪贴板）

### 画质
三档（流畅/均衡/高清），自动切「流畅」省流量；静态画面几乎零流量。

### 文件互传
顶栏「📁 文件」→ 浏览电脑目录、点文件下载（大文件流式落盘不占内存）、上传文件带进度条。

### 自检
顶栏「🩺 自检」→ 看电脑健康、帧率、自动补救记录。

### PWA 装成 App
手机浏览器菜单 → 「添加到主屏幕 / 安装应用」→ 图标、独立窗口、**监看时屏幕常亮**。

## 七、安全建议（重要）

- 口令用 **≥12 位强口令**；公网场景务必强
- 转发链接别带 `?token=` / `?pass=`（登录后会自己清掉，转发前别带）
- 别把局域网 8080 直接暴露公网；公网统一走中继 + `wss://`
- 中继用 `--strict` 禁陌生注册，重复登录失败会自动触发限速（5 次锁 5 分钟）
- 所有操作都有审计日志：手机端 `/devices` `/events` 可看，本地 `logs/security.log`

## 八、排障（常见问题）

| 现象 | 解决办法 |
|---|---|
| 手机打不开 | 防火墙放行 8080；确认同一 WiFi；走后门地址看是不是打印错了 |
| 画面卡 | 切「流畅」画质；局域网先测；跨网查中继带宽 |
| 控制没反应 | 先确认状态栏是「在线」；锁屏/睡眠下无法操作（与商业软件一致） |
| 打不出中文 | 中文走粘贴，需要电脑剪贴板可用；英文不受影响 |
| 设备一直离线 | 点「⚡ 唤醒」；检查电脑是否开机、中继 `--wol` 是否配了 MAC |
| 手机端是旧界面 | 强制刷新 / 清浏览器缓存，重新加载 v2.3 |

## 九、命令行参数速查

### server.py（电脑端）
| 参数 | 说明 |
|---|---|
| `--port` | 局域网端口（默认 8080） |
| `--token` | 访问口令（默认随机） |
| `--no-auth` | 关闭口令（仅可信内网） |
| `--share-dir` | 文件互传共享目录 |
| `--preset low/mid/high`、`--fps`、`--monitor` | 画质 / 帧率 / 显示器编号 |
| `--relay ws(s)://域名` | 跨网络中继地址 |
| `--id / --password` | 中继识别码与口令 |

### relay.py（中继）
| 参数 | 说明 |
|---|---|
| `--port` | 监听端口 |
| `--devices "ID:口令,ID2:口令2"`、`--strict` | 预注册设备（推荐） |
| `--conn-policy replace/reject` | 同识别码多端连接策略 |
| `--hb-timeout` | 设备心跳超时（秒） |
| `--wol "ID:MAC"`、`--wol-bcast` | 远程唤醒映射与广播地址 |
| `--xf-trusted` | 部署在 TLS 代理后时开 |
