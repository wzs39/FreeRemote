# FreeRemote 使用手册

FreeRemote——用手机浏览器远程控制电脑（监看 + 控制 + 文件互传），无需安装任何手机 App。

本手册按「从开机到熟练使用」的顺序，覆盖所有功能与常见问题。界面为网页，Windows / macOS / Linux 均可做被控电脑端，Android / iPhone / iPad 均可做手机端。

## 1. 这是什么 / 能做什么

| 能力 | 说明 |
|---|---|
| 监看 | 手机实时看到电脑屏幕（分块增量推流，静态画面几乎零流量） |
| 控制 | 触摸移动鼠标、点击、右键、滚动、打字、按组合键，就像在用电脑 |
| 文件互传 | 手机 ⇄ 电脑 双向传文件，带进度条 |
| 自检自愈 | 一键体检电脑环境；运行时自动降画质、断线自动重连 |
| 两种模式 | **局域网模式**（同一 WiFi） / **识别码模式**（不同网络，跨公网） |
| 多端 | 一台电脑可被多个手机同时监看控制 |

**版本提示**：页面顶栏有版本号（如 `v2.1`），据此确认手机端加载的是最新客户端。

## 2. 快速开始（局域网）

### 第一步：电脑端启动

**Windows**：双击 `run.bat`（首次会自动创建虚拟环境并安装依赖）。

**macOS / Linux**：

```bash
chmod +x run.sh && ./run.sh
```

或手动：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt   # Windows: .venv\Scripts\python.exe -m pip ...
.venv/bin/python server.py
```

启动后终端会打印类似：

```
 FreeRemote 已启动 —— 手机浏览器远程控制电脑
   本机预览 : http://127.0.0.1:8080/?token=AbCdEf
   手机访问 : http://192.168.1.23:8080/?token=AbCdEf
   手机访问(Tailscale跨网) : http://100.73.214.88:8080/?token=AbCdEf
   访问口令 : AbCdEf
```

> **固定口令 + 有效期（推荐）**：双击 `renew-token.bat` 一键生成新口令（**默认 7 天有效**），
> 启动横幅会显示有效期和剩余天数。到期后再启动，程序会**自动续期 7 天换新口令**并在横幅醒目提示（不会悄悄换成随机口令）；
> 服务**运行中到期**会立即拒绝新连接（已登录的会话 24 小时内不受影响）。
> `token.txt` 格式：第一行口令，第二行过期时间戳（Unix 秒，可留空 = 永久）。

### 第二步：手机连接

1. 手机与电脑连**同一个 WiFi / 局域网**；
2. 手机浏览器打开终端里的「手机访问」地址（Safari / Chrome 均可）；
3. 输入口令登录（见下节）。

> **Windows 首次运行**若弹出防火墙提示，点「允许访问」；没弹的话手动放行：
> ```
> netsh advfirewall firewall add rule name="FreeRemote" dir=in action=allow protocol=TCP localport=8080
> ```

### 启动 / 停止规范

- 重复启动会互相冲突。**重启前先运行 `stop.bat`（Win）或 `./stop.sh`（Mac/Linux）**把所有旧进程清掉，再重新 `run.bat`。
- 规则：**先 stop → 再 run**。
- `run.bat` 启动前会检查端口：默认检查 8080，`run.bat --port 其它端口` 则检查对应端口；
  **中继模式（`--relay`）不监听端口，自动跳过检查**。端口被占时会提示换端口或先 stop，不会误报。
- **中继连接失败不会无限重连**：连续失败 5 次后自动停止并打印排查指引（中继地址 / 识别码 / 口令 / 协议），
  退出后回到 `run.bat` 的暂停界面；再次双击 `run.bat`，检测到已有配置时可输入 **R 重新配置**（回车则继续用现有配置）。

## 3. 手机连接与登录

### 首次打开（两种模式的登录框）

| 模式 | 打开的网址 | 登录方式 |
|---|---|---|
| 局域网 | `http://<电脑IP>:8080/` | 输入 **口令 / token** |
| 识别码 | `https://<中继域名>/` | 输入 **识别码 + 口令** |

- 直接打开带 `?token=...` 或 `?id=...&pass=...` 的旧链接会自动登录，随后**自动把口令从地址栏抹掉**——转发链接不会泄漏口令。

### 更换口令时机

- 口令**已过期再启动**：程序自动续期 7 天换新口令，横幅打印新链接（记得更新手机书签）
- 口令**快到期**：剩余不足 3 天启动时横幅会加一行 ⚠ 提醒；运行 `renew-token.bat` 重发
- 服务**运行中到期**：新连接立即被拒绝（日志/审计记录「已过期口令访问被拒绝」），重启后自动换新
- **临时改 30 天**：命令行 `python server.py --renew-token 30`（数字任意；`0` = 永久）
- **永久口令**：在 `token.txt` 只写一行口令（不要第二行时间戳）
- 生成的随机口令**不含易混淆字符**（无 0/O、1/l/I），手机上更好手输

### 一次性口令（临时分享，10 分钟有效）

不想暴露长期固定口令时，用**临时口令**：

- 双击 `run.bat` → 提示选择时输 `O`（或命令行加 `--once`）
- 启动横幅会打印「一次性口令」和一次性链接：`http://<IP>:8080/?token=xxxxxxxx`
- 特点：**10 分钟有效、过期自动作废、不写盘**，适合临时把访问权分享给别人（用完即废，电脑重启后也不残留）
- 与 `token.txt` 固定口令**并存**：固定口令自己长期用，一次性口令临时发
- 两者独立：一次性口令过期不影响固定口令
- 登录后口令存在 HttpOnly Cookie 里（24 小时），不会出现在网址中。

### 状态栏怎么看

顶栏从左到右：状态点 + 状态文字 + 分辨率 / 画质 + 版本号 + 「🩺 自检」 + 「📁 文件」 + 画质档位。

| 状态点 | 含义 |
|---|---|
| 🟢 绿点 | 已连接 |
| 🟡 黄点 | 连接中 |
| 🔴 红点 | 已断开（会自动重连） |

## 4. 界面操作全解

界面从上到下：**顶栏 → 屏幕监看区 → 底部工具栏 → 键盘面板 / 文件面板**。

**横屏（推荐）**：把手机横过来，控制面板（工具栏 / 键盘 / 文件）会整合到画面**右侧的竖排面板**，按钮更大、更顺手；竖屏在画面下方。竖屏时顶部会出现一次「↻ 建议横屏」提示，点一下可不再提示。

| 区域 | 元素 | 作用 |
|---|---|---|
| 顶栏 | 状态 / 分辨率 | 显示连接状态、画面尺寸与画质 |
| 顶栏 | 🩺 自检 | 打开自检仪表盘 `/doctor` |
| 顶栏 | 📁 文件 | 打开 / 收起文件面板 |
| 顶栏 | 流畅 / 均衡 / 高清 | 切换画质 |
| 监看区 | 屏幕画面 | 触摸即操作电脑（见手势表） |
| 工具栏① | 左键/右键/中键、滚↑/滚↓、全屏 | 鼠标与滚轮、全屏 |
| 工具栏② | Ctrl/Alt/Shift/Win | 点选 = 按住修饰键（再点取消） |

## 5. 触摸与鼠标手势

在屏幕画面上的手势（与鼠标的对应关系）：

| 手机手势 | 电脑效果 |
|---|---|
| **轻点** | 左键单击 |
| **快速连点两次**（300ms 内、位置相近） | 左键双击（打开文件/程序） |
| **长按 0.5 秒** | 右键单击 |
| **单指拖动** | 移动鼠标 |
| **双指滑动** | 滚轮滚动（上下=纵向，左右=横向，速度可调） |
| 最下方六个按钮 | 左键/右键/中键/滚轮上/滚轮下/全屏 |

> 提示：画面里的鼠标光标是手机端根据指令本地绘制的，即使电脑采集不到光标也能看清当前鼠标位置。

### 操作设置（顶栏 ⚙）

- **鼠标灵敏度**：精准（0.4×，跟手变慢、便于精控）/ 标准（1×）/ 灵敏（1.8×，移得更快）。
- **双指滚轮速度**：慢 / 中 / 快。
- **单手模式**：工具栏贴到底部悬浮，拇指更好够到。
- 设置会自动保存（localStorage），下次打开手机页面仍然生效。

## 6. 虚拟键盘与组合键

点「⌨ 键盘」展开键盘面板：

- 上方输入框：输入后回车或点「发送」。**英文 / 符号会在电脑端直接逐键敲出**（不依赖剪贴板，更跟手）；**中文等非 ASCII** 以粘贴方式输入（会占用电脑剪贴板）。发送后输入框自动聚焦，可连续输入。
- 下方特殊键：`Esc / Enter / Tab / ⌫退格 / Del / 空格 / 方向键 / Home / End / PgUp / PgDn`；再往下是**常用快捷键**：`Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+Z / Ctrl+A / Ctrl+S / F5 / Win+D / Win+L / 任务管理器`。
- 输入框回车即发送；**中文输入法组词时按回车不会误发**（先确认候选词再点发送）。
- 组合键：先点工具栏的 `Ctrl / Alt / Shift / Win`（按钮会高亮 = 按住），再操作触屏或键盘；不用时再点一下解除。
- `CtrlAltDel`：点一次即发送（win 下可唤起锁屏/安全选项）。

## 8. 文件互传

顶栏点「📁 文件」打开文件面板：

- **目录浏览**：面板顶部显示当前路径，点「↑ 上级」返回，点目录进入下级；目录在前、按名排序。
- **下载（电脑→手机）**：点文件名即可下载到手机，有进度条。
- **上传（手机→电脑）**：底部的「选择文件」选好 → 点「上传」，实时进度条，完成后自动刷新列表。
- 支持**大文件**（分块流式，不占手机太多内存）、中文/特殊字符文件名。

> **共享根目录**：默认是电脑的「下载」文件夹，可用 `--share-dir "D:\共享"` 指定。文件功能与远程控制共用同一套鉴权（口令/识别码），口令勿外泄。

## 9. 识别码模式（不同网络）

要让手机在**别家 WiFi / 4G / 5G** 也能连家里的电脑，用「识别码 + 中继服务器」模式（与 TeamViewer / RustDesk 同架构）：电脑主动外连中继，手机打开中继网址输入识别码即可精准配对，**无需公网 IP / 端口转发**。

### 电脑端连接中继

```bash
python server.py --relay wss://你的中继域名 --id ABC123 --password 强口令
# 不指定 --id/--password 会自动生成并在终端打印
```

> **地址怎么填**：填域名即可（如 `relay.example.com`），程序会自动补全 `wss://`；
> 若误填了 `https://域名/一串路径/` 形式的穿透链接，**路径会自动去掉**，不用担心照抄整串链接。
> `run.bat` 的配置向导同样适用：输入域名（或整串穿透地址）都能识别。

### 手机端

打开 `https://你的中继域名/`，输入**识别码 + 口令**登录。地址栏只保留识别码、不含口令。

### 中继从哪来

- 有公网 VPS：`python3 relay.py --port 9090`；
- 免费托管：按 **`docs/DEPLOY_RELAY.md`** 部署到 Render / Fly.io（含 HTTPS/wss 配置）并常驻；
- 备选：**Tailscale**（两端装 App，手机开 `http://电脑TailscaleIP:8080/`）或 **SakuraFrp** 内网穿透（手机零安装，见 README）。

## 10. 自检与自动修复

系统自带「体检 + 自愈」，电脑端环境问题可提前发现并自动补救。

### 电脑端一键体检

```bash
python doctor.py                 # Windows: doctor.bat；Mac/Linux: ./doctor.sh
python doctor.py --port 8080     # 顺带检查端口占用
python doctor.py --relay wss://域名 --id 识别码 --password 口令   # 检查中继连通与配对
python doctor.py --test-input    # 实际测试鼠标注入（鼠标会移动 1 像素）
```

逐项输出 ✅/⚠️/❌，每个问题都附**补救方案**（缺依赖→装、mac 权限→在系统设置授权、端口占用→换端口、口令过短→加强等）。

### 运行时自动自愈

被控电脑在跑时自动执行，无需人工干预：

| 发现的问题 | 自动处理 |
|---|---|
| 屏幕采集连续失败 5 次 | 自动重建采集器 |
| 实际帧率低于目标一半 | 自动降一档画质 |
| 中继断线 | 5 秒自动重连 |
| 锁屏/睡眠 | 无法注入（与商业软件一致），需先解锁 |

### 手机端自检仪表盘（🩺 自检）

- 总体状态 ✅/⚠️/⏳ + 运行时长 / 帧率 / 画质 / 分辨率 / 重连次数；
- 逐项健康检查，未通过项直接给补救建议；
- 「警告与建议」和「自动补救记录」两个面板，每 3 秒自动刷新；
- 识别码模式下显示的是**电脑真实健康状态**（电脑每 5 秒上报遥测）。

## 11. 安全使用建议

| 事项 | 建议 |
|---|---|
| 口令 | 用 ≥12 位强口令；公网场景务必强口令 |
| 口令泄露 | 转发请发纯网址，别带 `?token=` / `?pass=` |
| 公网暴露 | 别把局域网 8080 直接映射公网；公网用 `https://` 并加限速（已内置 5 次锁 5 分钟） |
| 中继 | 公网中继用 `wss://`，可用 `--devices "识别码:强口令" --strict` 禁陌生注册 |
| 防入侵审计 | 登录/文件/连接/设备上下线都会写日志，可在手机端 `/devices` `/events` 查看 |
| 越权 | 文件面板从共享目录起可向上浏览目录树，请限定共享目录并管好口令 |

## 12. 远程唤醒 / 扫码登录 / 开机自启 / PWA

### 远程唤醒（WoL）：电脑关机也能开机

前提：电脑 BIOS 与网卡都启用了 Wake-on-LAN，且**中继与电脑在同一局域网**（比如中继跑在你家路由器/小主机上）。

1. 中继启动时配置唤醒映射：`python relay.py --wol "TEST01:AA-BB-CC-DD-EE-FF"`（识别码:网卡 MAC，可多个）
2. 手机端在设备离线时会出现「⚡ 唤醒」按钮 → 点击后中继向局域网广播 WoL 魔术包 → 电脑开机
3. 电脑开机后自动连回中继（配合下面的开机自启），手机端状态自动变回「在线」

> 中继部署在 Docker 时：`docker-compose.yml` 加环境变量 `RELAY_WOL=TEST01:AA-BB-CC-DD-EE-FF` 即可。

### 扫码登录（免输识别码）

电脑端（中继模式）连接成功后，终端会打印一个二维码（含一次性登录兑换券，120 秒有效）：

- 用**手机相机**扫终端里的二维码 → 自动打开中继登录页并**直接登录**，不用手输识别码和口令
- 二维码里的兑换券一次性使用、过期自动失效，口令本身不进入二维码

### 开机自启（电脑重启后自动运行）

```bat
install-autostart.bat        rem 注册 Windows 开机自启任务（自动识别模式）
```

- **有 `relay-config.txt`** → 注册中继模式自启（任务名 `FreeRemoteRelay`）
- **无 `relay-config.txt`** → 注册局域网/Tailscale 模式自启（任务名 `FreeRemoteLAN`，用 `token.txt` 固定口令）
- 电脑需设置为**自动登录**（开机不停在登录界面），否则任务不会触发
- 卸载自启：`schtasks /Delete /TN FreeRemoteLAN /F`（中继模式用 `FreeRemoteRelay`）；日志看 `auto.log`

### PWA：手机“添加到主屏幕”

手机浏览器打开 FreeRemote 后，在浏览器菜单里选「**添加到主屏幕 / 安装应用**」——图标、独立窗口、横屏启动；监看时**屏幕常亮**（Wake Lock），不再自动熄灭。

## 13. 日志与排查

所有日志都带 `[时间] [级别]` 前缀，级别分 `INFO`（正常）/ `WARN`（需留意）/ `ERROR`（错误）。
**查错误只需一条命令：`grep "[ERROR]" <日志文件>`**（Windows 可用记事本/VS Code 的搜索，或 Git Bash）。

| 文件 | 内容 | 编码 |
|---|---|---|
| `server.log` | 电脑端（server.py）运行日志：启动横幅、采集/推流/指令错误、自愈动作、安全事件 | UTF-8 |
| `relay.log` | 中继端（relay.py）运行日志：启动横幅、设备上下线、登录/限速/审计事件 | UTF-8 |
| `security.log` | 安全审计：登录成败、限速、白名单拒绝、文件上传下载、设备注册/上线/下线 | UTF-8 |
| `sessions.log` | 会话记录：设备/手机每次连接的起止时间与时长 | UTF-8 |
| `relay-auto.log` | 开机自启（中继模式）的原始输出（pythonw 无窗口时用） | — |

> 所有日志文件都存放在项目的 `logs/` 目录（UTF-8 编码，任何编辑器打开都不乱码）。
> 启动横幅最后一行会提示日志文件位置。

**分级约定**（一眼区分严重程度）：
- `[ERROR]`：限速拒绝、白名单拒绝、采集失败、推流错误、指令失败、中继断开、心跳超时强制下线等
- `[WARN]`：登录失败（口令/识别码错）、设备被顶替、自愈动作（自动降画质/重建采集器）等
- `[INFO]`：登录成功、设备上下线、文件操作、会话起止等正常事件

**排查示例**：
```bash
# 只看错误（推荐先跑这条）
grep "[ERROR]" logs/server.log        # 电脑端问题
grep "[ERROR]" logs/relay.log         # 中继/公网问题

# 看最近 20 条日志
tail -20 logs/server.log

# 找某个设备的记录
grep "TEST01" logs/relay.log
```

## 14. 命令行参数速查

### server.py（电脑端）

```bash
python server.py --port 8080 --fps 8 --preset mid --monitor 1 --token 口令
```

| 参数 | 说明 |
|---|---|
| `--port` | 端口，默认 8080 |
| `--fps` | 帧率 1–30，默认 8 |
| `--preset` | `low/mid/high`，默认 mid |
| `--monitor` | 显示器编号（1=主屏） |
| `--share-dir` | 文件共享根目录，默认「下载」文件夹 |
| `--token` | 局域网口令（默认随机生成） |
| `--no-auth` | 关闭鉴权（仅限完全可信局域网） |
| `--allow-ips` | IP 白名单，逗号分隔，其余一律 403 |
| `--tls-cert / --tls-key` | 同时给则启用 HTTPS |
| `--relay` | 识别码模式：中继地址，如 `wss://域名` |
| `--id / --password` | 识别码模式：设备识别码 / 口令 |

### relay.py（中继，部署到公网）

```bash
python3 relay.py --port 9090 [--xf-trusted] [--conn-policy replace|reject] [--hb-timeout 90]
```

| 参数 | 说明 |
|---|---|
| `--port` | 端口（默认 `$PORT` 或 9090） |
| `--devices` | 预注册 `"识别码:口令,..."` |
| `--strict` | 只允许 `--devices` 里的识别码 |
| `--xf-trusted` | 部署在 TLS 终结代理后时开（真实 IP 进限速/审计） |
| `--conn-policy` | 同识别码多端：`replace` 顶替（默认）/ `reject` 拒绝 |
| `--hb-timeout / --hb-interval` | 设备心跳超时与扫描间隔 |
| `--wol "识别码:MAC"` | 远程唤醒映射（环境变量 `RELAY_WOL`），手机离线时可发 WoL 开机 |
| `--wol-bcast` | WoL 广播地址（默认全子网广播） |

## 15. 常见问题 FAQ

**Q：手机打不开 `http://电脑IP:8080`？**
→ 确认同一 WiFi；Windows 放行防火墙；用电脑终端打印的地址；手机浏览器别输错端口。

**Q：显示「设备离线」？**
→ 识别码模式下是电脑没连中继或已关机。电脑连上后，手机端 3 秒内自动恢复（无需刷新）。

**Q：画面卡 / 帧率低？**
→ 顶栏切「流畅」档；或电脑端调低 `--fps`。弱网下「高清」会明显卡。

**Q：中文输入老是粘贴错？**
→ 中文用键盘面板输入是（复制→粘贴）方式发送，请确保输入框内容正确、电脑端该处可粘贴文本。

**Q：锁屏了能控制吗？**
→ 不能（与 TeamViewer 一致）。Windows 睡眠需先唤醒，远程桌面对话断开也会失效。

**Q：为什么重启后手机还是旧界面？**
→ 页面设置了禁止缓存，正常应都是最新。若异常，强制刷新一次即可（顶栏版本号核对）。

**Q：两台电脑用错同一个识别码？**
→ 默认新连接会顶替旧的并留「设备被顶替」告警；想禁止改用 `--conn-policy reject`。

**Q：担心有人爆破口令？**
→ 已内置：同一 IP 登录失败 5 次锁 5 分钟，并写入审计日志。请用强口令 + 公网 HTTPS。

**Q：怎么确认电脑健康状态？**
→ 手机端点「🩺 自检」，或电脑端跑 `python doctor.py`。

## 16. 术语表

| 术语 | 含义 |
|---|---|
| 局域网模式 | 电脑与手机同一网络直连（`--token` 口令） |
| 识别码模式 | 跨网络经中继，用「识别码 + 口令」配对 |
| 中继 / relay | 公网服务器，转发「手机 ⇄ 电脑」的帧与指令 |
| wss / ws | 加密 / 明文 WebSocket 协议（公网用 wss） |
| X-Forwarded-For | 代理写入真实客户端 IP 的请求头（`--xf-trusted` 读取它） |
| 分块推流 | 只传画面变化区域，静态零流量、低延迟 |
| MJPEG | 兜底推流格式（老浏览器/降级时用） |
